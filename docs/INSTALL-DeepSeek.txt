NoAIText iOS DeepSeek 0.1.1 — 真机测试版

默认：deepseek-flash，思考开启，强度 high。
手机独立运行，不需要Mac常开或Cloudflare。使用你自己的DeepSeek API额度。
B站接口链与PC插件一致：视频信息 -> 官方player/wbi/v2字幕列表 -> 字幕正文 -> 同版提示词评分。
封面保留请求的宽高、比例及裁切，仅转JPEG后写入标记。

0.1.1更新：修正小火箭模块的三层花括号参数替换。旧版KEY不能区分缺少Key/参数未展开/认证失败，本版分别显示NO KEY/PARAM/AUTH。
从0.1.0更新：替换全部4个JS和同名模块，编辑参数确认原Key仍在，重新编译配置；不会要求你重新发送Key。

一、替换TEST探针
1. 把包发到手机，在“文件”解压。
2. Script里的4个JS复制到 iCloud云盘/Shadowrocket/Script/。本地可读即可，不要求iCloud同步成功。
3. 把 NoAIText.DeepSeek.srmodule 放到 iCloud云盘/Shadowrocket/Modules/。
4. 在小火箭“配置 > 模块”停用旧TEST探针和以前的NoAIText测试模块，启用本包新模块。不要同时启用旧改图脚本。
5. 打开新模块“编辑参数”，填写自己的DeepSeekKey；保存后重新编译当前配置。
6. HTTPS解密沿用现有已信任的证书；确认模块新增主机名已合并到当前配置，并开启HTTP/2解密。

二、只需做一次的B站网页登录（用于取字幕）
PC插件借助浏览器已有登录Cookie取字幕。iOS App登录不会自动变成Safari网页登录，所以手机也需要建立这份登录态。
1. 保持小火箭和本模块开启，在Safari打开 https://www.bilibili.com/ 并登录自己的B站账号。
2. 登录后再次打开 https://www.bilibili.com/ ，然后打开 https://api.bilibili.com/x/web-interface/nav 。看到 isLogin 为 true 即可，不用复制或发送页面内容。
3. 脚本从这些B站请求中只保存所需Cookie在小火箭本机存储；不会输出Cookie，不会发给DeepSeek。默认保留14天，失效后重新登录并访问上述页面。
4. 回原版B站App，退出重开并刷新推荐。日常继续使用原版App，无需Safari看视频。
不要把Cookie或DeepSeek Key发给别人，也不用把它们发给Codex。

三、结果
AI 37%：模型对字幕的“疑似AI文案”评分，非经过校准的概率，不能证明作者用了AI。
绿色：低于40%；黄色：40%至69%；红色：70%及以上。
LOGIN：未取得或登录态过期，按第二节重新登录。App已登录也可能出现此状态。
NO KEY：没有填写自己的Key。
PARAM：模块参数没有正确传入/占位符未展开；请确认模块和脚本均为0.1.1，刷新模块并重新编译配置。
AUTH：Key已传入，但DeepSeek返回401/403认证拒绝。
MAP：该封面还没有匹配到视频ID，未调用AI；重启B站并刷新推荐使信息流先建立映射。直播、图文等非普通视频不保证支持。
NO SUB：B站未返回可用字幕。不会用标题/简介代替字幕，不会因此给0%。
SHORT：字幕不足50字，暂不检测。
TIMEOUT：在等待时间内未完成。刷新时可重试；思考模式可能较慢。
RATE：接口限流；BALANCE：余额不足；ERROR：网络/API/结果格式异常。
没有任何标记：可能是直播/图文等非普通视频、非archive图片、图片超过800×600或800KB、App复用了旧图片缓存，或解密/脚本未命中。
调试只看小火箭日志中的 [NoAIText]，不要分享完整HTTP请求、Cookie或模块参数。

四、可修改设置
小火箭“配置 > 模块 > 本模块 > 编辑参数”：
模型：deepseek-flash（默认），可改deepseek-v4-pro或未来官方支持的模型ID。
思考：true（默认）/false。
强度：low/high（默认）/max，关闭思考时不发送此项。
等待秒：默认45，范围5~50。模块脚本总超时60秒。
并发：默认2，范围1~3。这是基于本机存储租约的软限制，不是严格计费上限。
缓存天：默认7，范围1~30。
修改后保存并重新编译配置。换模型、思考、强度、Key或登录态后不会复用旧评分。

五、实际边界
首次未缓存的封面要等待取字幕、排队和模型推理，可能数秒到几十秒；不能保证无感。命中本机评分缓存时不再调用AI。
重复视频尽量合并请求，并发租约在小火箭跨脚本环境中没有原子锁，不能保证绝对不重复计费。
只处理官方接口返回可用字幕的普通视频；不下载音视频、不在手机跑语音识别，不把机器转写字幕本身当AI文案证据。
推荐/搜索/空间/动态中的JSON卡片会建立封面映射；如果某个页面改用protobuf/gRPC，本版不会猜测视频身份，需要后续针对该页面适配。
旧图片可能在App内存/磁盘缓存中；重启、刷新或换一批推荐测试。请求加了按分钟变化的图片缓存标记，响应禁用缓存，仍不能强制App更新已经展示的图片。
评分成功缓存含视频ID和模型设置，不含字幕正文；字幕仅在内存中处理。登录Cookie单独保存在小火箭本地，停用模块不会自动清除。需要移除时清除本模块脚本存储，或在B站退出所有设备使该会话失效。
本包不含任何个人Key、Cookie或日志。不要转发自己填写过参数后的模块、.meta或小火箭备份。

验收建议：先测试一条有字幕的普通视频，确认AI数字；同视频刷新查看缓存，再检查4:3推荐卡片与16:9动态卡片的比例。首次手机链路仍需真机验证。
